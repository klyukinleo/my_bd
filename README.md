**Что делает программа:** Позволяет регистрировать пользователей, запрашивая их имя, фамилию и возраст, валидирует корректность ввода возраста и сохраняет данные в коллекцию.

## Как запустить
1. Убедитесь, что у вас установлен Python 3.
2. Откройте терминал или командную строку в папке с проектом.
3. Выполните команду: python main.py

## Сценарии проверки (Тесты)

### Проверка 1: Обычный (позитивный) сценарий
* **Входные данные:** 
  * Firstname? → `Leonid`
  * Lastname? → `Klyukin`
  * Age? → `19`
* **Ожидание:** Программа успешно принимает все данные и выводит красиво отформатированный профиль игрока.
* **Результат:** 
  ```text
  Firstname: Leonid
  Lastname: Klyukin
  Age: 19
  ```

### Проверка 2: Граничный сценарий (проверка на ошибку / неверный ввод)
* **Входные данные:** 
  * Firstname? → `Leonid`
  * Lastname? → `Klyukin`
  * Age? → `-5` (или `abc`, или `0`)
  * Age? (повторный запрос) → `19`
* **Ожидание:** Программа отклоняет некорректный возраст (`-5`, `abc`, `0`), не прерывает работу, а заново запрашивает ввод, пока не получит целое положительное число. После ввода `19` успешно завершает регистрацию.
* **Результат:** Запрос повторяется до ввода корректного числа, после чего профиль успешно выводится на экран.
